## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Make sure you have [Git](https://git-scm.com/) and [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/savaliyabhargav20/Portfolio.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Portfolio
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

4. **Start the development server:**
   ```bash
   npm start
   # or
   npm run dev
   ```
   *The application should now be running on `http://localhost:3000` (or whichever port your framework uses).*
